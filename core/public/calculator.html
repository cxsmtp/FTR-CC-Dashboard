    Each one's organizations, groups or workspaces, and Everything this token can see.

    Each one's default branch: its code lines, its commits in the last 365 days (so how often it changes) and the people who committed in the last 90 days.

    How it is measured

    How it is measured, with cloc-fusion's engine: each repository's default branch is fetched from git into a temporary folder on this server, back to a year ago and without file contents but those counted (or read from the platform's API as an archive), counted, and the folder deleted at once. Lines are counted as cloc counts them: by each file's language, without blank lines or comments; dependencies, build output and generated files are left out. Commits are those on the default branch in the last 365 days, merges left out: how often a repository changes sets its Fusion scans. Developers are the people who committed in the last 90 days, bots left out, counted once across the run: only the counts are kept, never a name or an email. Up to 1,000 repositories a run, 2 GB each; files git marks as binary are skipped. Minified and generated code is sized as Checkmarx sizes it: a file of 64 KB or more with over 512 bytes a line of code, or one over 1 MB, counts as its bytes divided by 40.

    When the code must not leave the customer, or they have many organizations: they open cloc-fusion (the file above; no install, nothing sent anywhere but their own git hosts), add their connections with a read-only token, press Calculate Fusion credits, and send you its report: any of the files it makes (JSON, HTML, CSV or Markdown). The JSON says the most (lines by language); the others give each repository's lines as one figure. A report holds counts and names of repositories, never code or tokens; its list of contributors is not read here.

    Drop the cloc-fusion report here (JSON, HTML, CSV or Markdown), or . Each repository it measured becomes a project, with its lines by language, commits, change frequency and developers; a project with the same address, or the same name, is replaced.

    When the code must not leave the customer: they run cloc, a free open-source tool (Count Lines of Code), where the code is and send you only the counts. docker.io/aldanial/cloc is cloc's official image, from its author Al Danial.

    One file per repository

    On Windows with Podman (Windows cmd, one line):

    podman run --rm -v "C:\code\payments-api:/src:ro" docker.io/aldanial/cloc --json --quiet /src > payments-api.json

    Or with cloc installed:

    cloc --json --quiet --report-file=payments-api.json C:\code\payments-api

    Or many repositories in one file

    Run on the folder that holds them; each folder in it becomes a project:

    podman run --rm -v "C:\code:/src:ro" docker.io/aldanial/cloc --json --by-file --quiet /src > all-repos.json

    CSV works too (--csv).

    Drop cloc results here (.json or .csv), or . A file for one repository is a project named after the file; rename it below. A project of the same name is replaced.
